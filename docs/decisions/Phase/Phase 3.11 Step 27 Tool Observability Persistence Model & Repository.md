# 十二、Transaction

写入必须使用 Repository 内部自己的事务边界。

参考现有：

```text
LLMUsageRepository.create()
```

模式。

即：

```text
session_factory
    ↓
Session
    ↓
session.begin()
    ↓
INSERT
    ↓
COMMIT
```

异常：

```text
INSERT failure
    ↓
ROLLBACK
    ↓
RepositoryError
```

不要让调用方负责：

```text
session.commit()
session.rollback()
```

这样保持和现有 Repository 一致。

SQLAlchemy 的 `Session.begin()` context manager 会在成功时提交、异常时回滚，适合作为这个 Repository 的单次写操作边界。
