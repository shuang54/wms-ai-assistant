## 3. Evaluation Flow

```text
Case -> Question -> Evaluation Schema Context (t2s_eval)
  -> REAL TextToSQLService (DeepSeek) -> Generated SQL
  -> REAL SQLValidator -> REAL SQLExecutor (READ ONLY)
  -> Result Checker (ground truth, applied AFTER execution)
```

- Ground truth never reaches the LLM (no leakage).
- SQL is never repaired / rewritten.
- Validator rejections are recorded, never bypassed.

> Run transparency: the first benchmark attempt completed all 12 cases but
> aborted while serialising the snapshot (`created_at` is a `date`, which is
> not JSON-native). That was a tooling defect in the persistence step, not a
> DeepSeek or database failure, and it produced no artifact. The baseline
> below comes from the single subsequent run; no result was selected or
> discarded.

## 6. Result Mismatches

- `group_by_chunk_count_per_document`:
  - generated SQL: `SELECT d.id, d.title, COUNT(c.id) AS chunk_count
FROM t2s_eval.documents d
LEFT JOIN t2s_eval.chunks c ON c.document_id = d.id
GROUP BY d.id, d.title
LIMIT 1000;`
  - actual: [[4, 'Delta Manual', 4], [2, 'Beta Notes', 3], [3, 'Gamma Guide', 1], [1, 'Alpha Report', 2]]
  - expected: [[1, 2], [2, 3], [3, 1], [4, 4]]
- `having_chunk_count_greater_than`:
  - generated SQL: `SELECT d.id, d.title
FROM t2s_eval.documents d
JOIN t2s_eval.chunks c ON c.document_id = d.id
GROUP BY d.id, d.title
HAVING COUNT(c.id) > 2
LIMIT 1000;`
  - actual: [[4, 'Delta Manual'], [2, 'Beta Notes']]
  - expected: [[2, 3], [4, 4]]
- `semantic_dependent_document_and_chunk`:
  - generated SQL: `SELECT d.id, d.title, COUNT(c.id) AS chunk_count
FROM t2s_eval.documents d
LEFT JOIN t2s_eval.chunks c ON c.document_id = d.id
GROUP BY d.id, d.title
LIMIT 1000;`
  - actual: [[4, 'Delta Manual', 4], [2, 'Beta Notes', 3], [3, 'Gamma Guide', 1], [1, 'Alpha Report', 2]]

## 10. Limitations

- Single DeepSeek run; LLM output is nondeterministic.
- 12 cases only; not a production-quality estimate.
- Result expectations assume the evaluated SQL targets `t2s_eval`;
  the regression dataset still references `public.*` and the
  logical->physical mapping lives in this evaluation layer only.
- Validator acceptance does not imply result correctness.
- Security is out of scope here (see section 8).
